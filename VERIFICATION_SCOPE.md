# Verification Scope

C.A.S.E. is a bounded local artifact proof surface.

## Required boundary properties

- proposed movement enters through the declared boundary service;
- standing is re-bound at commit and is not inherited from prior approval;
- commit attestation binds the governing basis, authority scope, evidence lineage, current state, runtime identity, and contract identity;
- refusal produces no protected bind;
- same-condition replay verifies the same governing basis;
- changed-condition replay does not silently reuse prior standing;
- tampering breaks lineage or release-hash verification.

## Stable verification rule

The repository's stable verification path is authoritative for the public proof claim. Experimental layers must not be presented as equivalent evidence until independently hardened.

## Claim boundary

A passing local artifact proof is not production certification, third-party certification, or universal no-bypass proof.
