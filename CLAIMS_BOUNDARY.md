# Claims Boundary

This repository is buyer-readable only when its claims remain bounded to the local artifact proof surface.

## Allowed claims

The following claims are admissible:

- local artifact proof surface
- commit-time admissibility
- standing re-bound at commit
- runtime receipt
- replay comparison
- lineage tamper detection
- bounded C.A.S.E. / Elyria seam
- candidate pilot surface
- buyer-reviewable proof package
- commercial corridor scoping surface

## Forbidden claims

The following claims are not admissible:

- production certified
- third-party certified
- universal governance proof
- deployed no-bypass enforcement
- C.A.S.E. certification
- psychological safety certification
- legal or compliance guarantee
- clinical, financial, or employment-law guarantee
- proof outside the release package
- full Elyria protected kernel disclosure
- authorization to reuse, commercialize, or derive from this work

## Required buyer wording

Use this wording:

```text
C.A.S.E.–Elyria Systems Boundary Layer is a buyer-reviewable local proof package showing commit-time admissibility, standing re-bound at commit, commit attestation, runtime receipt, replay, and lineage verification for governed AI execution. It is not production-certified, not third-party certified, and not a deployed no-bypass network. It is a proof surface for evaluating a bounded pilot or commercial corridor.
```

## Boundary rule

No claim may exceed the evidence preserved in the release package.
