# Pilot Lane

This repository is not a production deployment. It is a buyer-reviewable proof surface for deciding whether a bounded pilot or commercial corridor should be scoped.

## Buyer pilot options

### 1. Ninety-minute proof-surface review

A structured walkthrough of the local artifact, proof suite, claim boundary, and buyer-relevant use cases.

Output: review notes, gap list, pilot/no-pilot recommendation.

### 2. One-use-case stress test

A single buyer-provided use case is mapped into the C.A.S.E. / Elyria boundary model and tested against admissibility, refusal, escalation, replay, and lineage expectations.

Output: use-case stress result and bounded pilot recommendation.

### 3. One workflow corridor pilot

A narrow workflow corridor is scoped for commit-time admissibility review. This does not include production deployment unless separately agreed.

Output: corridor definition, movement conditions, refusal paths, receipt/replay expectations, and production gates.

### 4. One commit-time admissibility proof package

A buyer-specific proof package is created around one effect-bearing movement path.

Output: proposal shape, boundary envelope, contract conditions, commit rule, attestation fields, receipt shape, replay criteria, lineage checks.

## Buyer use cases

Potential pilot lanes include:

- HR AI decision support
- healthcare or administrative escalation
- employee-facing AI assistant
- federal or enterprise AI workflow
- customer-service AI escalation
- sensitive recommendation workflow
- AI procurement / approval-to-operation bridge
- compliance review handoff
- risk-aware automation approval

## Pilot intake questions

Before a pilot can be scoped, define:

1. What movement is effect-bearing?
2. Who or what has authority to approve it?
3. What evidence must remain valid at commit?
4. What human challenge condition can reopen review?
5. What risk condition causes escalation or halt?
6. What receipt must be preserved?
7. What replay result would prove continuity?
8. What lineage break should fail loudly?

## Commercial boundary

A pilot requires written scope. This public repository does not grant a commercial deployment license.
