# Claim Boundary

## This repo claims

This repo demonstrates a local artifact proof surface for proposed effect-bearing movement entering a boundary layer before protected consequence may bind.

The repo proves, inside this preserved release package, that:

- proposed movement must enter through a boundary service envelope
- standing is re-bound before commit and is not inherited
- admissibility is evaluated before protected consequence may bind
- authority scope, evidence lineage, current state, runtime identity, and contract identity are attested
- failed admission produces refusal / no-bind behavior
- replay compares governing conditions explicitly
- lineage verification detects tamper
- release hashes verify preserved artifacts

## This repo does not claim

- production deployment hardening
- third-party certification
- universal governance proof
- deployed network no-bypass enforcement
- proof outside this release package
- public exposure of protected Elyria / VERITA kernel internals
- customer-specific corridor certification

## Core invariant

**Proposed movement enters.  
Boundary resolves.  
No protected consequence binds without the boundary result.**
