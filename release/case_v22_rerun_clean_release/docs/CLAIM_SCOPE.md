# Claim Scope

## What this release claims
This release claims **local artifact truth** for the package in this zip:
- UI submits
- boundary service envelope gates entry
- authoritative contract loads and verifies
- `runtime_commit_gate` decides
- commit attestation emits from execution
- receipt emits from execution
- replay compares governing conditions explicitly
- lineage verification is available and tamper-loud

## What this release does not claim
- production deployment truth
- network service hardening
- independent third-party certification beyond the verifier-facing artifacts included here
- proof of the original CASE artifact


Presentation discipline: receipt/lineage verification is a separate integrity phase and should not be presented as if it determines admissibility.
