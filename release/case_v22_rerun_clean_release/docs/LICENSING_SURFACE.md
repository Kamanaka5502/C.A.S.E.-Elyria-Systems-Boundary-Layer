# LICENSING_SURFACE.md

## Commercial surface
- CASE UI / reviewer flow
- proof brief export
- decision trace / replay / lineage views

## Core enforceable value
- contract identity verification before commit
- commit-boundary admissibility re-evaluation
- commit attestation emitted from execution
- receipt lineage verification
- replay governed by explicit condition comparison

## Licensing discipline
Do not market the wrapper as if it carries runtime authority when it does not. The wrapper is the visible surface; the enforcement layer is the licensable core value.
