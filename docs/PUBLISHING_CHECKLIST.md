# Publishing Checklist

Before making this repository public:

1. Confirm the repository is intended as a proof surface, not as production infrastructure.
2. Confirm `npm run verify` passes.
3. Confirm no customer material, private legal material, credentials, tokens, keys, or live deployment data are present.
4. Keep the claim scope bounded to the local artifact release.
5. Do not add language implying certification, universal proof, or deployed no-bypass infrastructure.
6. Keep proprietary runtime depth and customer engagement material outside the public repo.
